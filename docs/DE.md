# SHAE — Deutsche Dokumentation

## Installation
Führe `scripts/install.sh` aus, um die Crystal REST API zu installieren.

## Plattform
CLI-Tool (Crystal-Sprache).

## Build
`crystal build src/rest_api.cr -o shae-rest-api --release`

## Release
GitHub Release v0.1.0 verfügbar.
