# SHAE — Documentación en Español

## Instalación
Ejecute `scripts/install.sh` para instalar la API REST en Crystal.

## Plataforma
Herramienta de línea de comandos (CLI) en lenguaje Crystal.

## Build
`crystal build src/rest_api.cr -o shae-rest-api --release`

## Release
GitHub Release v0.1.0 disponible.
